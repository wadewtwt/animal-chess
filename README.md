# 斗兽棋 (Animal Chess)

## 微信小游戏发布操作流程

本项目的微信小游戏发布流程分为以下几个简单的步骤：

### 1. 构建发布
- 打开 Cocos Creator。
- 在顶部菜单栏点击 **项目 (Project)** -> **构建发布 (Build)**。
- 选择发布平台为 **微信小游戏**。
- 直接点击 **构建 (Build)** 按钮等待完成即可。

### 2. 资源上传至 OSS
- 构建完成后，在发布输出目录（通常在 `build/wechatgame/` 下）会生成一个名为 `remote` 的文件夹（包含所有需要远程加载的资源包）。
- 将该 `remote` 文件夹上传到您配置好的 OSS（对象存储服务）中。

### 3. 微信开发者工具预览与上传
- 打开 **微信开发者工具**。
- 导入生成的微信小游戏项目目录（一般是 `build/wechatgame/` 文件夹）。
- 确认资源路径无误后，即可在开发者工具中进行调试、预览，或者直接上传提审。
